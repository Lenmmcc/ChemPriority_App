# ToxPi 分数四位小数显示设计

## 目标

将应用中所有面向用户展示的 ToxPi 分数统一显示为小数点后四位，减少不同化合物因两位小数格式化而呈现为相同分数的情况。

## 范围

- ToxPi 结果表中的 ToxPi 分数显示为四位小数。
- ToxPi 径向图中的分数标签显示为四位小数。
- ToxPi 柱状图中的柱顶分数标签显示为四位小数。
- 综合筛查流程和一键批量查询复用相同的显示规则。

## 保持不变

- ToxPi 计算继续使用完整浮点精度。
- 两阶段排名规则、候选范围、展示范围和 PA/PBM/DF 权重不变。
- 排序继续使用完整精度分数及现有确定性次级排序规则。
- Excel、ZIP 等导出数据中的 ToxPi 列保持数值类型和完整精度，不转换为四位小数字符串。
- 排名序号和其他非 ToxPi 指标的显示精度不变。

## 实现设计

在共享展示层集中定义 ToxPi 分数的四位小数格式，避免各页面分别处理：

1. 图表生成函数使用统一的四位小数格式生成径向图和柱状图标签。
2. Streamlit 结果表通过列格式配置将 `toxpi` 和 `initial_toxpi` 等面向用户展示的 ToxPi 分数格式化为四位小数。
3. 传给计算、排序和导出流程的 DataFrame 不做取整或字符串转换。

## 数据流

完整精度输入 → 完整精度 ToxPi 计算 → 完整精度排序与导出 → 仅在 Streamlit 表格和图表标签处格式化为四位小数。

## 测试

- 回归测试验证径向图标签包含四位小数。
- 回归测试验证柱状图标签包含四位小数。
- 页面展示测试验证 ToxPi 表格应用四位小数格式。
- 数值精度测试验证计算结果和导出表仍保留超过四位的小数，不因展示格式发生取整。
- 运行 ToxPi 针对性测试、页面 AppTest（如现有测试支持）以及完整单元测试集。

## 验收标准

- 两个完整精度不同但前两位相同的 ToxPi 分数，在界面中可显示为不同的四位小数。
- 所有用户可见的 ToxPi 分数格式一致。
- 修改前后的排名顺序和导出数值完全一致。
- 现有测试和新增回归测试全部通过。
