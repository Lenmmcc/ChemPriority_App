# ChemPriority 网站指南续写设计

日期：2026-07-28

## 目标

以 `C:\Users\Administrator\Desktop\Chem_Priority网站指南.docx` 为格式与内容起点，保留已经完成的“综合筛查流程环节”，轻度校对其中的明显错别字和产品名称写法，并续写其余五个网站模块，形成可直接交付的完整中文网站操作指南。

## 范围

续写以下模块：

1. ADMETlab 毒性数据获取
2. ToxPi 毒性评估
3. EPI Suite 环境归趋
4. 化合物用途查询
5. 一键批量查询

现有“综合筛查流程环节”只做轻度校对，不改变流程含义、参数解释、截图顺序和页面结构。

## 内容结构

每个续写模块沿用第一部分的写作节奏：

1. 模块编号与模块名称
2. “X.1 功能介绍”
3. 必要时保留或补充流程图
4. “X.2 操作”
5. 按实际页面顺序说明上传、设置、运行、查看与下载
6. 插入当前本地网站的最新界面截图
7. 对联网查询、缓存、超时、失败记录或外部网站操作给出必要说明

正文保持面向普通使用者，优先描述“在哪里点击、输入什么、会得到什么”，避免展开实现代码和内部技术细节。

## 格式约束

- 以原 DOCX 为模板，保留 A4 页面、现有页边距、等线字体、正文大小、行距和段后间距。
- 保留现有一级模块的自动编号形式和每个模块另起一页的习惯。
- 截图居中插入，宽度不超过正文版心，避免拉伸变形。
- 沿用原稿简洁的图示方式，不引入新的装饰性配色、封面或复杂表格。
- 不新增页眉、页脚、页码或目录，除非原稿本身已有相应元素。
- 不删除原有流程图或截图；只有在明显过时且有当前界面替代时才更新。

## 内容依据

- 页面名称、按钮、标签页、输入要求、参数和输出名称以当前工作区中的 `app.py`、`pages/` 与相关 `src/` 逻辑为准。
- 操作截图来自当前本地运行的 ChemPriority 网站。
- 涉及 ADMETlab、PubChem、EPI Suite、EPA CompTox、ECHA 或 ChemSpider 的描述应区分站内操作、外部网站操作和联网接口限制。
- 不承诺外部服务始终可用；指南应提示用户查看失败记录、重试、缓存或备用上传流程。

## 校对边界

允许修正：

- `execl` 为 `Excel`
- `EPIsuite` 为 `EPI Suite`
- `Toxpi` 为 `ToxPi`
- 明显的标点、空格、大小写和语句不通顺问题

不改变：

- 第一部分的技术结论和流程顺序
- 已有图表所表达的业务逻辑
- 用户自定义的章节命名风格

## 截图计划

- ADMETlab：上传与模板、输入数据/连接状态、结果下载。
- ToxPi：输入与权重设置、数据审查、ToxPi 图谱、稳健性分析与下载。
- EPI Suite：上传与目标指标、网页端预测、外部结果上传与合并下载。
- 化合物用途查询：标识符补全、EPA/ECHA/GHS/来源属性、用途图表与结果下载。
- 一键批量查询：多文件映射、模块选择与 EPI 补充、运行设置、进度与结果下载。

截图数量按可读性控制；同一界面能完整说明多个连续步骤时不重复截取。

## 交付与验证

- 保留桌面原文件不变，在工作区生成续写后的新 DOCX。
- 使用 Microsoft Word 后台导出 PDF，并将每页渲染为 PNG。
- 逐页检查文字截断、图片模糊或变形、异常空白页、分页断裂、字体替换和图文脱节。
- 修正后重新渲染，直至全部页面通过视觉检查。
- 最终只交付续写后的 DOCX，不交付内部检查用的 PDF 和 PNG。
